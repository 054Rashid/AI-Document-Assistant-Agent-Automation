# Demo questions

Try these after running the ingestion script:

1. `What should I do if my laptop stops working?`
2. `How long do I have to submit a travel claim?`
3. `What are the meal reimbursement rules?`
4. `Convert 40 USD to INR.` (works when the LLM/agent mode is enabled)
5. `Find the policy about equipment requests.`

For a fresher-level demo, first show `/api/search` so the interviewer can see the retrieved chunks. Then show `/api/agent` to explain how the agent decides which tool to use.
